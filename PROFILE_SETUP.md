## Publish the portfolio website

1. Open https://github.com/bconnell/bconnell/settings/pages.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main**, then **/docs**, and save.
4. Wait for the Pages deployment to finish and open the actual published URL.
5. Check desktop/mobile layout, keyboard navigation, project links, and the contact link.
6. Only then put the live URL in the GitHub profile Website field and add it to your LinkedIn profile and resume.

GitHub Pages activation is a separate repository setting. The presence of `docs/index.html` alone does not mean the site is live. No custom domain is configured here.
